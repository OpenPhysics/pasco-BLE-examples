About this example

Plot sensor data as an X-Y graph where:

  • Y-axis: Any sensor measurement
  • X-axis: Time or another sensor measurement

This enables parametric plotting (e.g., Force vs. Position, Acceleration X vs. Acceleration Y, Voltage vs. Current).

Requirements

  • Chrome or Edge browser (Web Bluetooth)
  • Any PASCO BLE sensor device
